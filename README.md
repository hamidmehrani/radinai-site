# RadinAI (`radinai.ir`) — استودیو مهندسی نرم‌افزار، هوش مصنوعی و محصولات وردپرس

وب‌سایت رسمی **رادین هوش (`radinai.ir`)** — استودیو مهندسی نرم‌افزار، اتوماسیون هوش مصنوعی، راهکارهای نرم‌افزاری اختصاصی سازمانی و محصولات وردپرس ایران (پرچم‌دار **دفتریار نسخه ۱٫۰**).

## ویژگی‌های معماری
- **۲۱ مسیر استاتیک پیش‌رندرشده (`SSG` فوق‌سریع با مصرف رم ناچیز)** + صفحه سفارشی `/404.html` + `sitemap.xml` خودکار.
- **تایپوگرافی استاندارد بومی فارسی (`$persian-rtl`):** فونت‌های متغیر سلف‌هاست `YekanBakhFaNum-VF.woff2` و `IRANYekanXVFaNumVF.woff2` بدون فراخوانی سرور خارجی، `font-synthesis: none`، `letter-spacing: 0` و تبدیل صددرصدی ارقام به فارسی.
- **سیستم حرکتی و تعاملی (`VibeFarsi × GSAP 3 + ScrollTrigger + Lenis`):**
  - میز کار تعاملی ۳ حالته در بخش اول صفحه (`محصولات وردپرس`، `پلتفرم اختصاصی`، `اتوماسیون هوش مصنوعی`)
  - شبیه‌ساز زنده ۵ تبه پیشخوان وردپرس **دفتریار نسخه ۱٫۰** (پیش‌نمایش فاکتور رسمی و مالیات، چرخش کارت‌به‌کارت ضدتقلب، گارد سود ترب و اسنپ‌پی، استودیو برچسب پستی و تست پینگ پیامک)
  - نمایشگاه کامل ۶ سامانه پروداکشن (`Hamesu`, `Cvly`, `Exvorta`, `Firoza`, `Daftaryar`, `Automation Engines`) و ۶ برند صادراتی بین‌المللی `Exvorta Web` (`Spicevo`, `Nutave`, `Stonvi`, `Aurum`, `Meridian`, `Vestra`)
  - تخمین‌گر هوشمند دامنه، زمان‌بندی و هزینه پروژه + پالت جستجوی سریع فرمان (`Ctrl + K`)
- **توابع لبه کلودفلر (`Cloudflare Pages Functions`):**
  - `GET /api/health` — پایش سلامت سرویس لبه
  - `POST /api/inquiry` — ثبت استعلام پروژه با گارد ضداسپم، تولید کد پیگیری یکتا (`RDN-...`) و انتقال مستقیم به واتس‌اپ

## دستورات ساخت و راستی‌آزمایی
```bash
npm run build            # ساخت ۲۲ فایل HTML و دارایی‌ها در dist/
npm run verify           # اجرای گیت لینک‌ها، JSON-LD، ارقام فارسی و عدم نشت انگلیسی
npm run functions:check  # کامپایل آزمایشی توابع Cloudflare Pages Functions
npm run qa               # اجرای ممیزی ۴۲ نما در Playwright (دسکتاپ ۱۴۴۰ و موبایل ۳۹۰)
```
