# سیستم طراحی، مراجع Mobbin و معماری RadinAI (`radinai.ir`)

## ۱. هویت بصری و کارگردانی هنری («آتلیه هندسه و مهندسی رادین هوش»)
طراحی بومی فارسی (`RTL`) در تراز جوایز جهانی وب (Awwwards) با ترکیب **VibeFarsi × Mobbin** و انضباط کامل تایپوگرافی فارسی (`$persian-rtl`):

### پالت رنگی نام‌گذاری‌شده (۵ توکن پایه با کنتراست استاندارد WCAG AAA/AA)
- **`--rdn-ink` (`#070B14` — شب‌رنگ لاجوردی عمیق):** زمینه صحنه‌های نمایشی تیره (Hero، پیشخوان زنده دفتریار، سینمای افقی Exvorta Web و فوتر مانیومنتال).
- **`--rdn-slate-dark` (`#0E1628` / `#142038` — سنگ لوح مهندسی):** کارت‌های شیشه‌ای و پنل‌های کنسول تعاملی با گرید ظریف هندسی گره‌چینی ایرانی.
- **`--rdn-paper` (`#F5F4EE` — کاغذ معماری گچی) + `--rdn-sheet` (`#FFFFFF`):** زمینه روشن و خوانا برای برگه‌های راهکارهای سازمانی، پرونده‌های مهندسی و جداول مقایسه.
- **`--rdn-lapis` (`#1D4ED8` روی روشن / `#38BDF8` روی تیره — لاجورد الکتریک):** اکشن‌های اصلی، مسیرهای فعال و شاخص‌های تعاملی.
- **`--rdn-turquoise` (`#0D9488` روی روشن / `#14B8A6` روی تیره — فیروزه‌ای نیشابور) و `--rdn-copper` (`#B45309` / `#F59E0B` — مس برنزی):** سیگنال‌های سلامت، گیت‌های تست پاس‌شده و نشان پرچم‌دار محصولات وردپرس.

### تایپوگرافی و قواعد فارسی (`$persian-rtl`)
- **تیترها:** `Yekan Bakh Variable` سلف‌هاست (`/fonts/YekanBakhFaNum-VF.woff2`)، `font-synthesis: none`، `letter-spacing: 0`، `text-wrap: balance`.
- **متن بدنه و رابط کاربری:** `IRANYekanX Variable` سلف‌هاست (`/fonts/IRANYekanXVFaNumVF.woff2`)، کف سایز `13px`، ارتفاع خط `1.82`، ارقام فارسی یکنواخت (`tabular-nums`).
- **شناسه فنی انگلیسی:** منحصراً داخل `<bdi dir="ltr" class="ltr-tech">` با فونت سلف‌هاست `IBM Plex Mono`.
- **صفر کلیشه طراحی ماشینی:** بدون رنگ‌کردن تک‌کلمه وسط تیترها، بدون حروف بزرگ فاصله‌دار بالای تیترها، بدون شماره‌گذاری تزئینی روی کارت‌های غیرترتیبی و بدون تله‌ی `opacity: 0` در CSS پایه.

## ۳. نقشه ۲۱ مسیر کامپایل‌شده استاتیک

3. `/products/daftaryar/` — برگه جامع محصول دفتریار (`Daftaryar v1.0.0`)

5. `/solutions/web-engineering/` — طراحی و مهندسی وب‌سایت اختصاصی و فروشگاه‌های پرترافیک

8. `/solutions/enterprise/` — طراحی و پیاده‌سازی راهکارهای نرم‌افزاری اختصاصی سازمانی
